# Tube Brain AI

A powerful YouTube analytics and AI automation platform built with Kotlin Multiplatform + Compose for Web.

## Features
- Analyze Channel - Deep AI-powered YouTube channel analysis
- Analyze Video - Complete video data extraction
- Extract Transcript - YouTube video transcript extraction
- AI Prompts - Pre-built AI prompt library
- Thumb Downloader - YouTube thumbnail downloader
- Niche Finder - AI-powered niche discovery
- Visuals Finder - Multi-API visual asset finder
- Start Automation with AI - Full 30-day content plan generator

## Setup
1. Open the project in IntelliJ IDEA or Android Studio
2. Set your API keys in `AppConfig.kt`
3. Run `./gradlew wasmJsBrowserDevelopmentRun` to start dev server
4. Run `./gradlew wasmJsBrowserProductionWebpack` for production build

## Tech Stack
- Kotlin Multiplatform
- Compose Multiplatform (Web/WASM)
- Ktor HTTP Client
- Kotlinx Serialization
- YouTube Data API v3
- Google Gemini API
- Pixabay API / Pexels API
